# Demonstração pública Amaral

Site estático para GitHub Pages que reproduz, por etapas, uma jornada de demonstração anterior: pedido, visita, orçamento, aceite, ordem, andamento, conclusão da equipe e confirmação do cliente.

## Hospedagem

Publique o conteúdo desta pasta em um repositório GitHub e ative **Settings → Pages → Deploy from a branch**, apontando para a raiz da branch desejada. Não há etapa de build, servidor, credencial, banco, CDN, tracking ou chamada a IA.

## Limites da demonstração

- É uma reprodução estática e guiada; a página não executa IA nem envia ou recebe mensagens.
- A conversa livre é deliberadamente desativada.
- Agenda e preços são ilustrativos, sem ligação com dados ou operações da Amaral.
- Os participantes foram anonimizados como clientes e equipe simulados; esta pasta não contém identificadores de casos, dados pessoais, caminhos internos ou configurações.

## Verificação local

Abra `index.html` através de um servidor estático simples para que o navegador possa carregar `demo.json`. Para a validação estrutural usada nesta entrega, veja os comandos no histórico da tarefa.
